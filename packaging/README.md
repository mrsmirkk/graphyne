# Graphyne 0.1.0-alpha.11 — Windows x64

Ранняя альфа-версия IDE на Rust + GPUI в стиле JetBrains Fleet. Сборка для ознакомления:
часть функций из ТЗ ещё не реализована (см. «Ограничения»).

## Запуск

- **Двойной клик по `graphyne.exe`** — откроются проекты, которые были открыты при выходе,
  с теми же вкладками, курсором, прокруткой, панелями и положением окна. Если открывать
  нечего — начальное окно Welcome: Open Folder и недавние проекты.
- **Close Project** (меню ⚙) закрывает проект и возвращает на Welcome; такой проект при
  следующем запуске сам не откроется.
- **Из терминала:** `graphyne.exe "C:\путь\к\проекту"` — проект откроется сразу.
- Папку проекта можно перетащить на `graphyne.exe` в Проводнике.
- Другую папку можно открыть изнутри: кнопка ⊞ в шапке (Open Folder… и недавние проекты)
  или меню ⚙. Каждый проект открывается в своём окне.

Установка не нужна: это один переносимый файл, всё (иконки, грамматики, тема) встроено.

## Требования

- Windows 10/11 x64, видеокарта с поддержкой DirectX 11. На ноутбуке с двумя видеокартами
  Graphyne рисует встроенной (если к ней подключён экран): окно появляется примерно за 0,2 с
  вместо 0,45 с, а дискретная видеокарта не просыпается. Чтобы рисовать дискретной, выберите
  «Высокая производительность» для `graphyne.exe` в Параметрах Windows → Дисплей → Графика или
  задайте `GRAPHYNE_GPU=high`.
- Шрифты **JetBrains Mono** и **Inter** (если их нет — используются Cascadia Mono / Segoe UI).
- **Подсветка ошибок, автодополнение, документация** — нужен языковой сервер в `PATH`:
  `rust-analyzer`, `pyright-langserver` (или `basedpyright`, `pylsp`), `gopls`, `clangd`,
  `vtsls` / `typescript-language-server`, `lua-language-server` и т.д. Без сервера работают
  подсветка синтаксиса и автодополнение по словам из файла.
- **PHP, Ruby, C#, Java, Kotlin, Scala** — сервер ставится в один клик: при открытии файла
  Graphyne предлагает карточку «Code insight for …» (или щёлкните по значку ⚡). Сервер кладётся
  в папку Graphyne (`%APPDATA%\Graphyne\lsp`), не в глобальные npm / gem / dotnet. Нужен сам язык:
  PHP — Node.js (intelephense, ~150 МБ); Ruby — Ruby (Ruby LSP, ~5 МБ); C# — .NET SDK 8–11
  (csharp-ls, ~100 МБ); Java — Java 21+ (Eclipse JDT LS, 50 МБ); Kotlin — ничего (сервер JetBrains
  со своей Java, 370 МБ загрузки, 1,2 ГБ на диске); Scala — Java 17+ (Metals, ~180 МБ). Свой сервер
  в `PATH` всегда важнее.
- **Python** — если его нет на компьютере, Run / Debug предложат **Install Python 3.13** (через uv,
  около 30 МБ, без записи в PATH и реестр). Когда в проекте появляется `.py`-файл (или при
  первом Run / Debug), Graphyne сам создаёт `.venv` и ставит туда `debugpy`. Если выбран
  интерпретатор без debugpy (системный Python, conda, Poetry…), отладчик берётся из папки
  Graphyne, а в само окружение ничего не ставится; Run, Debug, pyright и
  встроенные терминалы используют этот `.venv` — `pip install` в терминале ставит пакет туда же,
  откуда его возьмёт Run. Пакеты проекта — из `requirements.txt`, а если его нет, из
  `dependencies` в `pyproject.toml` (вместе с группой `dev`, как делает uv) — Graphyne ставит в
  `.venv` только после вопроса (Install / Not now / Don't ask again): без согласия ничего не
  ставит, а когда список пакетов меняется — спросит снова (смена номера версии проекта не в счёт).
  Если есть `uv.lock` — через `uv sync`, иначе менеджером пакетов проекта. Выключается в
  Settings → Run & Debug.
- **Проекты Poetry, PDM, Pipenv и conda** (`poetry.lock` или `[tool.poetry]`, `pdm.lock`,
  `Pipfile`, `environment.yml`) Graphyne после вопроса ставит их собственным инструментом:
  `poetry install`, `pdm sync`, `pipenv sync --dev`, `conda env create / update` (подойдут и
  mamba / micromamba) — и дальше Run, отладка, pyright и терминалы работают в окружении, которое
  сделал инструмент, где бы оно ни лежало (для conda в PATH добавляются её папки с DLL, как после
  `conda activate`). Poetry, PDM и Pipenv ставить не нужно — Graphyne запускает их через uv; conda
  должна быть установлена (Miniforge или micromamba).
- **uv по умолчанию** — окружения создаются и пакеты ставятся через [uv](https://docs.astral.sh/uv/),
  это в разы быстрее pip. Если uv не установлен, Graphyne при первой надобности скачивает свою
  копию (около 15 МБ, сверяет SHA-256), без интернета работает pip. Проект остаётся обычным
  `.venv` с pip внутри — его можно открыть и без uv. Graphyne сам выберет pip, если у pip
  настроен свой источник пакетов (`pip.ini`, `PIP_INDEX_URL`), который uv не читает, а если uv не
  смог что-то установить — предложит «Use pip for this project». Если пакет нужно компилировать, а
  компилятора C++ нет, подскажет поставить Build Tools или взять Python постарше. uv выключается
  в Settings → Run & Debug.
- **Выбор интерпретатора Python** — клик по версии Python справа в строке состояния (или
  «Python: Select Interpreter…» в поиске действий). В списке — окружения проекта, все Python,
  которые знает `py`, окружения conda и `python` из PATH. Там же «Create / Recreate .venv with
  Python 3.x» — если библиотека ещё не поддерживает самый новый Python (старый `.venv` уходит в
  Корзину), «Choose python.exe…» для интерпретатора в другом месте, «Install Python 3.x» — uv
  поставит нужную версию в свою папку, и «Package manager» — автоматически (с причиной выбора),
  uv или pip. Выбор запоминается для каждого проекта.
- **Нет библиотеки** — если pyright подчеркнул импорт, `Alt+Enter` → «Install package "…"»
  запустит uv или pip для интерпретатора проекта во вкладке терминала (известные расхождения имён
  учтены: `cv2` → `opencv-python`, `PIL` → `pillow`, `yaml` → `pyyaml` и др.). После установки
  подчёркивание пропадёт само.
- **Отладка JavaScript и TypeScript** — нужен Node.js. При первой отладке Graphyne скачивает
  отладчик Microsoft `js-debug` (около 1 МБ, сверяет SHA-256) в свою папку в `%APPDATA%\Graphyne`;
  без интернета можно распаковать его самому и указать путь в переменной `GRAPHYNE_JS_DEBUG_PATH`.
  Файлы `.ts` запускаются как есть на Node 23.6 и новее. Внутренние кадры Node в стеке скрыты.
- **Отладка Rust** — нужен только Rust (`cargo`). Перед отладкой проект собирается `cargo build`,
  а отладчик CodeLLDB (около 50 МБ, сверяется SHA-256) Graphyne скачивает при первой отладке в
  свою папку в `%APPDATA%\Graphyne`, если `lldb-dap` или `codelldb` нет в PATH. Работают точки
  останова, шаги, значения прямо в коде, переменные с типами Rust (String, Vec, HashMap,
  структуры) и консоль выражений (`p.x + p.y`; вызывать методы LLDB не умеет). Внутренние кадры
  std / core в стеке скрыты.
- **C и C++** — нужен компилятор `gcc` / `g++` (MinGW-w64, w64devkit) в PATH: Run собирает и
  запускает файл, отладка компилирует его с `-g -O0` и отлаживает через `gdb`, если тот умеет DAP
  (GDB 14+ с Python), а иначе через тот же CodeLLDB, что и Rust (у GDB из MinGW и w64devkit
  Python нет). Работают точки останова, шаги, значения в коде, структуры, массивы, `std::string`
  и элементы `std::vector`, выражения в консоли.
- **Java** — нужен JDK. Отладчик свой, встроенный в Graphyne (протокол JVM — JDWP), скачивать
  ничего не нужно. Файл и исходники его пакета собираются `javac -g`, программа работает во вкладке
  терминала. Точки останова с условиями и логпоинты, шаги, record'ы, коллекции и словари по
  содержимому, выражения в консоли: переменные, поля, `[индекс]`, методы без аргументов, арифметика.
- **Kotlin** — нужны JDK и компилятор Kotlin (`kotlinc`). Отладчик тот же, встроенный: data-классы,
  коллекции Kotlin и свойства (`point.x`, `items.size`) в консоли.
- **Scala** — нужны JDK и scala-cli. Отладчик тот же, встроенный: case-классы, коллекции Scala,
  переменные, которые меняет лямбда (`total`), понятные имена фреймов.
- **Dart** — нужен только Dart SDK: отладчик и языковой сервер входят в него. Программа при отладке
  работает во вкладке терминала, точки останова, шаги, объекты, словари и выражения Dart в консоли.
- **C#** — нужен .NET SDK. Run и отладка работают с проектом (ближайший `.csproj`) и, начиная с
  .NET 10, с одиночным `.cs`-файлом. Отладчик netcoredbg Graphyne скачивает при первой отладке
  (около 3 МБ, сверяет SHA-256). Вывод программы при отладке — в консоли отладчика, ввод с
  клавиатуры во время отладки не поддерживается (ограничение netcoredbg).
- **Отладка Ruby** — нужен только Ruby 3.1 или новее: отладчик (gem `debug`) входит в него.
  Точки останова, шаги, значения в коде, структуры и хеши, выражения Ruby в консоли.
- **Lua** — ставить ничего не нужно. Если Lua на компьютере нет, Run и отладка работают на Lua 5.4
  из отладчика lua-debug, который Graphyne скачивает при первой надобности (около 10 МБ, сверяет
  SHA-256). Отладка: точки останова, шаги, значения в коде, таблицы и выражения в консоли.
- **Отладка Go** — нужен только Go. Если отладчика Delve (`dlv`) нет, Graphyne один раз собирает
  его командой `go install` в свою папку (загрузку проверяет сам Go). Точки останова, шаги,
  значения в коде, срезы, map и структуры, выражения в консоли; вывод программы — в консоли
  отладки.

## Что есть

- Островной интерфейс Fleet, свой значок приложения.
- Редактор с подсветкой tree-sitter для 24 языков и форматов: Rust, Python, JavaScript,
  TypeScript/TSX, Go, C, C++, C#, Java, Kotlin, PHP, Dart, Lua, Ruby, Scala, Swift, HTML,
  CSS, SQL, JSON, TOML, YAML, Bash.
- LSP: ошибки, подсказки типов, автодополнение с автоимпортом, документация, Alt+Enter с
  превью, счётчики `N usages` по данным сервера, инкрементальная синхронизация правок.
- Отладчик DAP: условные точки останова и logpoint'ы, точки сохраняются в
  `.graphyne/breakpoints.json` проекта, ввод в программу во вкладке терминала.
- Встроенный терминал с выносом в отдельное окно.
- Если для языка не установлен компилятор или среда (gcc/g++, rustc, JDK, Go, Node.js…),
  Graphyne говорит об этом при открытии файла и вместо запуска — что и откуда поставить.
- Run для HTML/CSS: локальный сервер на 127.0.0.1, страница сама обновляется после
  каждого сохранения. Стрелка рядом с ▷ — пресеты аудита (cargo audit, clippy, nmap,
  gobuster, valgrind, strace, gdb), каждый в своей вкладке терминала.
- Git: ветка, изменения, коммит (открытые файлы сохраняются перед ним), история с графом
  веток, метки на полях с откатом. Клик по файлу во вкладке Git открывает сравнение с
  последним коммитом в две колонки (подсвечены изменённые слова, Shift+колесо — прокрутка
  вбок); галочки у блоков изменений позволяют закоммитить только часть правок файла.
- Операции с файлами в дереве проекта (правый клик): New File, New Folder, Rename, Delete,
  Copy Path / Copy Relative Path, Reveal in File Explorer. Имя вводится прямо в строке дерева
  (`src/utils/io.py` создаст и папки), удаление — в Корзину после подтверждения, открытые
  вкладки следуют за переименованными файлами и папками. Одиночный клик открывает файл и
  оставляет клавиатуру в дереве (работают F2 и Delete), двойной — переводит в редактор.
- Дерево проекта с клавиатуры: ↑ / ↓ и Home / End — переход по строкам, → раскрывает папку или
  переходит внутрь, ← сворачивает её или поднимается к родителю, Enter открывает файл в
  редакторе, Пробел — превью.
- Перетаскивание мышью в дереве переносит файлы и папки (целевая папка подсвечивается, вкладки
  следуют за файлами). Файлы и папки, брошенные из Проводника, копируются в проект.
- Меню «Файл» (☰ слева в шапке): New File / Folder, Open File, Open Folder, Save, Save As,
  Save All, Close Tab, Close All Tabs, Close Project, Settings, Exit.
- Базы данных (вкладка **Database** справа): подключения → таблицы и представления → колонки
  с типами и первичными ключами; раскрытые ветки запоминаются между запусками. **PostgreSQL** и **MySQL / MariaDB** (кнопка «+» → хост, порт,
  база, пользователь, пароль, режим SSL, Test Connection; таблицы других схем видны как
  `схема.таблица`) и **SQLite** — он встроен, ставить ничего не нужно; файл `.db` / `.sqlite` из
  дерева проекта открывается как база. Пароли хранятся в диспетчере учётных данных Windows, а не
  в файлах Graphyne. К PostgreSQL и MySQL можно подключаться через SSH-туннель (SSH tunnel → On:
  хост, порт, пользователь, файл ключа, пароль или фраза-пароль ключа). Работает встроенный в
  Windows клиент OpenSSH, поэтому `~/.ssh/config`, ключи и ssh-agent действуют как в терминале.
  SQL-консоль: ▷ Run в шапке или Ctrl+Enter выполняет запрос под
  курсором или выделение, Stop прерывает долгий запрос, текст консоли сохраняется. Результаты и таблицы —
  в виртуализированной таблице (200 000 строк прокручиваются плавно): сортировка по колонке,
  ширина колонок мышью, стрелки, Ctrl+C копирует ячейку, Ctrl+Shift+C — строку.
- Редактирование данных: в таблицах с первичным ключом — двойной клик, Enter или просто набор
  текста в ячейке, Set NULL, добавление и удаление строк. Изменения подсвечены, пока **Submit**
  не сохранит их одной транзакцией (если строку успели изменить в другом месте, не сохранится
  ничего) или **Revert** не отменит. Так же правится и результат запроса в консоли, если это
  простой `SELECT` из одной таблицы (`SELECT id, name FROM users WHERE age > 20`) и в нём есть
  первичный ключ; после Submit запрос выполняется заново. Остальные результаты (JOIN, GROUP BY,
  вычисляемые колонки и псевдонимы, представления) только для чтения — над таблицей написано
  почему. Экспорт результатов и таблиц в CSV, JSON и SQL INSERT.
- Импорт CSV (разделитель — запятая, точка с запятой или табуляция; кодировка UTF-8, UTF-16 или
  Windows-1251 из русского Excel — определяется сама): правый клик по подключению →
  **Import CSV as New Table…** создаёт таблицу с угаданными типами колонок (целые, дробные,
  текст; `007` остаётся текстом; первая колонка `id` с разными числами становится первичным
  ключом), правый клик по таблице → **Import CSV…** добавляет строки, колонки сопоставляются по
  заголовку. Одной транзакцией: либо все строки, либо ни одной.
- External Libraries: стандартная библиотека и зависимости (Cargo, site-packages Python).
- Secrets Guard, hex-редактор, автосохранение. Файлы больше 16 МБ открываются как простой
  текст, без подсветки и анализа.

## Расширения (плагины)

Как Extensions в VS Code или плагины JetBrains: расширение — папка в `plugins\` рядом с
`graphyne.exe` (`plugin.json` + `init.lua` на Lua). Оно может добавить **язык** (подсветка
через свою грамматику tree-sitter, языковой сервер, команда запуска, комментарии), **тему
оформления**, горячие клавиши, вкладки в панелях. Новое или изменённое расширение
подхватывается сразу, без перезапуска.

Страница **Plugins** (кнопка «+» в шапке левой панели или главное меню ⚙): список
расширений, что каждое добавляет, включение/отключение, разрешения и выбор темы.

Установить расширение — кнопки **Install from file…** (`.zip`, в том числе «Download ZIP» с
GitHub) и **From folder…** там же. Graphyne покажет название, версию, автора и разрешения, которые
оно просит (все выключены, пока вы их не отметите), и скопирует его в `plugins\` только после
кнопки Install. Повторная установка обновляет расширение: старая версия уходит в Корзину,
выданные разрешения остаются.

В комплекте два примера: тема **Nord** и язык **Zig**. Грамматике Zig нужно разрешение
«native» — это машинный код, поэтому Graphyne загружает его только после вашего согласия.
Как писать свои — `plugins\README.md`.

## Настройки

Вкладка **Settings** (Ctrl+, или ⚙ → Settings…): тема (встроены Graphyne Dark и
Graphyne Light, плагины могут добавить свои); шрифты интерфейса, редактора и
терминала (выпадающий список с поиском по шрифтам, установленным на компьютере; по умолчанию
JetBrains Mono и Inter); размеры шрифта, подсказки «N usages» и подсказки типов, автосохранение и его задержка, оболочка
терминала (PowerShell, cmd, Git Bash, WSL — что найдено), открывать ли при запуске проекты
прошлой сессии. Изменения применяются сразу и сохраняются в `%APPDATA%\Graphyne\settings.json`.

Раздел **Keymap** там же — горячие клавиши около 50 команд, с поиском по названию или по самим
клавишам («ctrl+d»). Клик по сочетанию записывает новое (Esc — отмена), «+» добавляет ещё одно,
«×» удаляет. Если сочетание уже занято другой командой, рядом появится предупреждение и кнопка
**Remove there** — убрать его оттуда. Изменённые команды можно вернуть по одной (↺) или все сразу
(**Reset shortcuts**). Меню, поиск действий и стартовый экран показывают ваши сочетания.

## Свои настройки на Lua (LuaJIT)

Файл `~/.config/graphyne/init.lua` (на Windows `C:\Users\<имя>\.config\graphyne\init.lua`)
выполняется при запуске и заново при каждом сохранении. «+» → **Open init.lua** создаст его
с примерами. Там же лежит `plugins.json` — какие расширения выключены и какие разрешения выданы.
Папки можно переопределить переменными `GRAPHYNE_CONFIG_DIR` и `GRAPHYNE_PLUGINS_DIR`.

| API | Что делает |
| --- | --- |
| `graphyne.settings.set("editor.font_size", 15)` | размер шрифта редактора; также `terminal.font_size`, `editor.autosave_delay_ms` |
| `graphyne.keymap.set("editor" / "global", "ctrl-alt-d", fn)` | своя горячая клавиша |
| `graphyne.buffer.get_text()`, `get_cursor()`, `get_selection()`, `get_path()`, `node_at_cursor()` | текст, курсор, выделение, узел синтаксического дерева |
| `graphyne.buffer.insert(text)`, `replace_selection(text)`, `set_text(text)` | правка активного файла |
| `graphyne.terminal.run("cmd", { tab = "имя" })` | команда во вкладке терминала |
| `graphyne.ui.notify(msg, "error"?)`, `print(...)` | уведомление |
| `graphyne.ui.register_tab({ title, side = "left"/"right", items = fn })` | своя вкладка в панели; элементы — строки или `{ text, detail, on_click }` |
| `graphyne.workspace.root()`, `graphyne.workspace.open(path, line)` | папка проекта, открыть файл |
| `graphyne.themes.register({ name, ui = {…}, syntax = {…} })` | тема оформления |
| `graphyne.languages.register({ name, extensions, line_comment, lsp, run, grammar })` | новый язык |

- Lua работает в отдельном потоке: зависший скрипт не тормозит интерфейс, а через 2 секунды
  останавливается. Поэтому JIT-компиляция по умолчанию выключена (её код такие проверки
  пропускает); включить можно в `init.lua` через `jit.on()`.
- Расширения работают в песочнице: без `os.execute`, `io.popen`, `ffi`, `debug`;
  `require` загружает модули только из папки самого расширения. Больше — только через
  разрешения на странице Plugins. `init.lua` — ваш файл, ему доступно всё.

## Ограничения альфа-версии

- Базы данных: представления и результаты запросов с JOIN или GROUP BY только для чтения.
  Горячие клавиши пока не переназначаются в Settings.
- Выбор блоков для частичного коммита живёт до закрытия IDE.
- PowerShell в терминале в русской раскладке превращает Ctrl+Z и похожие сочетания в букву
  (Ctrl+Z → «я»): так ведёт себя сам PowerShell (модуль PSReadLine), в обычной консоли
  Windows то же самое. Graphyne отправляет правильный управляющий код — например, cmd
  показывает ^Z, а Ctrl+C останавливает программу.
- Запуск дольше цели ТЗ (30 мс): основное время уходит на инициализацию DirectX.
- Проверено только на Windows 11 x64.
