# Graphyne 0.1.0-alpha.2 — Windows x64

Ранняя альфа-версия IDE на Rust + GPUI в стиле JetBrains Fleet. Сборка для ознакомления:
часть функций из ТЗ ещё не реализована (см. «Ограничения»).

## Запуск

- **Двойной клик по `graphyne.exe`** — откроется окно выбора папки проекта.
- **Из терминала:** `graphyne.exe "C:\путь\к\проекту"` — проект откроется сразу.
- Папку проекта можно перетащить на `graphyne.exe` в Проводнике.
- Другую папку можно открыть изнутри: кнопка ⊞ в шапке (Open Folder… и недавние проекты)
  или меню ⚙. Каждый проект открывается в своём окне.

Установка не нужна: это один переносимый файл, всё (иконки, грамматики, тема) встроено.

## Требования

- Windows 10/11 x64, видеокарта с поддержкой DirectX 11.
- Шрифты **JetBrains Mono** и **Inter** (если их нет — используются Cascadia Mono / Segoe UI).
- **Подсветка ошибок, автодополнение, документация** — нужен языковой сервер в `PATH`:
  `rust-analyzer`, `pyright-langserver` (или `basedpyright`, `pylsp`), `gopls`, `clangd`,
  `vtsls` / `typescript-language-server`, `lua-language-server` и т.д. Без сервера работают
  подсветка синтаксиса и автодополнение по словам из файла.
- **Отладка Python** — `debugpy` (`python -m pip install debugpy`) или путь к папке с ним
  в переменной окружения `GRAPHYNE_DEBUGPY_PATH`.
- **Отладка Rust / C / C++ / Go** — `lldb-dap` или CodeLLDB, `gdb` ≥ 14, `dlv` (не проверено).

## Что есть

- Островной интерфейс Fleet, свой значок приложения.
- Редактор с подсветкой tree-sitter для 24 языков и форматов: Rust, Python, JavaScript,
  TypeScript/TSX, Go, C, C++, C#, Java, Kotlin, PHP, Dart, Lua, Ruby, Scala, Swift, HTML,
  CSS, SQL, JSON, TOML, YAML, Bash.
- LSP: ошибки, подсказки типов, автодополнение с автоимпортом, документация, Alt+Enter с
  превью, счётчики `N usages` по данным сервера, инкрементальная синхронизация правок.
- Отладчик DAP: условные точки останова и logpoint'ы, точки сохраняются в
  `.graphyne/breakpoints.json` проекта, ввод в программу во вкладке терминала.
- Встроенный терминал с выносом в отдельное окно.
- Run для HTML/CSS: локальный сервер на 127.0.0.1, страница сама обновляется после
  каждого сохранения. Стрелка рядом с ▷ — пресеты аудита (cargo audit, clippy, nmap,
  gobuster, valgrind, strace, gdb), каждый в своей вкладке терминала.
- Git: ветка, изменения, коммит (открытые файлы сохраняются перед ним), история с графом
  веток, метки на полях с откатом. Клик по файлу во вкладке Git открывает сравнение с
  последним коммитом в две колонки (подсвечены изменённые слова, Shift+колесо — прокрутка
  вбок); галочки у блоков изменений позволяют закоммитить только часть правок файла.
- External Libraries: стандартная библиотека и зависимости (Cargo, site-packages Python).
- Secrets Guard, hex-редактор, автосохранение. Файлы больше 16 МБ открываются как простой
  текст, без подсветки и анализа.

## Плагины и настройки на Lua (LuaJIT)

Файл `~/.config/graphyne/init.lua` (на Windows `C:\Users\<имя>\.config\graphyne\init.lua`)
выполняется при запуске и заново при каждом сохранении — перезапуск не нужен. Кнопка «+» в
шапке левой панели → **Open init.lua** создаст его с примерами. Плагины лежат рядом, в
`plugins/` (`имя.lua` или `имя/init.lua`). Папку можно переопределить переменной
`GRAPHYNE_CONFIG_DIR`.

| API | Что делает |
| --- | --- |
| `graphyne.settings.set("editor.font_size", 15)` | размер шрифта редактора; также `terminal.font_size`, `editor.autosave_delay_ms` |
| `graphyne.keymap.set("editor" / "global", "ctrl-alt-d", fn)` | своя горячая клавиша |
| `graphyne.buffer.get_text()`, `get_cursor()`, `get_selection()`, `get_path()`, `node_at_cursor()` | текст, курсор, выделение, узел синтаксического дерева |
| `graphyne.buffer.insert(text)`, `replace_selection(text)`, `set_text(text)` | правка активного файла |
| `graphyne.terminal.run("cmd", { tab = "имя" })` | команда во вкладке терминала |
| `graphyne.ui.notify(msg, "error"?)`, `print(...)` | уведомление |
| `graphyne.ui.register_tab({ title, side = "left"/"right", items = fn })` | своя вкладка в панели; элементы — строки или `{ text, detail, on_click }` |
| `graphyne.workspace.root()`, `graphyne.workspace.open(path, line)` | папка проекта, открыть файл |
| `graphyne.plugins.allow("имя", { "os", "io", "ffi" })` | снять ограничения песочницы для плагина |

- Lua работает в отдельном потоке: зависший скрипт не тормозит интерфейс, а через 2 секунды
  останавливается. Поэтому JIT-компиляция по умолчанию выключена (её код такие проверки
  пропускает); включить можно в `init.lua` через `jit.on()`.
- Сторонние плагины работают в песочнице: без `os.execute`, `io.popen`, `ffi`, `debug`;
  `require` загружает модули только из папки самого плагина. `init.lua` — ваш файл, ему
  доступно всё.

## Ограничения альфа-версии

- Нет баз данных / DataGrid, окна настроек (настройки — через `init.lua`), сворачивания
  блоков кода.
- Выбор блоков для частичного коммита живёт до закрытия IDE.
- Запуск дольше цели ТЗ (30 мс): основное время уходит на инициализацию DirectX.
- Проверено только на Windows 11 x64.
